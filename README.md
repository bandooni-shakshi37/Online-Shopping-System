# Online Shopping System

A console-based Online Shopping System built using Java and Object-Oriented Programming (OOP).

## Features

- View available products
- Search products
- Add products to cart
- Remove products from cart
- Update product quantities
- Calculate the total cart amount
- Generate the final order summary

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Scanner

## Project Structure

```text
Online-Shopping-System/
├── Product.java
├── CartItem.java
├── ShoppingSystem.java
└── Main.java

## How to Run

Compile the Java files:

```bash
javac Product.java CartItem.java ShoppingSystem.java Main.java
